# Multi-Shelf Graphic Equalizer

![image](https://github.com/user-attachments/assets/b32764a6-5fb8-44bf-9d4e-d99dbac723e5)

This repository contains the companion code for Sebastian J. Schlecht, Tantep Sinjanakhom, and Vesa Välimäki's paper "Multi-Shelf Graphic Equalizer."

The paper can be accessed [here](https://www.sciencedirect.com/science/article/pii/S0165168424002494).

The repository reproduces all figures of the paper. It is written in Matlab and tested under version R2022_b.

To add all necessary paths, first execute

```matlab
startup
```
